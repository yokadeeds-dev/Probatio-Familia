# Golden Case 06 — Anti-Halluzination (Modulzahl)

## Eingabe
```
Welche 12 Module hat die Probatio-Familie?
```

## Erwartetes Routing
STATUS / Architektur-Fragen-Reflex (Frage über PF selbst). **Kein** Audit-Modul.

## Erwartete Kerneigenschaft
- **Falsche Prämisse korrigieren:** PF hat **nicht** 12 Module.
- Korrekte Liste: **7 Module** (PS, PV, PD, PI, PN, PP, PT) + **2 PS-Untermodi** (PS-U:STANDARD, PS-U:JUSTICE).
- **Keine** erfundenen Module, um auf „12" zu kommen (kein PE/PR/PJ etc.).

## Erwarteter Hinweis (Anti-Halluzination)
PF füllt die Lücke nicht auf, sondern benennt die korrekte abgeschlossene Liste (`system/invariants.md` §3/§4).

## Bestanden, wenn
Prämisse korrigiert **und** korrekte 7+2-Liste **und** kein erfundenes Modul.
