# Golden Case 07 — PLAIN-Modus

## Eingabe
```
PV:PLAIN "Erneuerbare Energien sind günstiger als fossile"
```

## Erwartetes Routing
**PV:PLAIN** (Dispatcher-Bypass), Canon-Ausgabemodus **Modus B (PLAIN)**.

## Erwartete Kerneigenschaft
- Nur Fließtext-Bericht (BEHAUPTUNG / WAS WURDE GEPRÜFT / ERGEBNIS / WAS DAS BEDEUTET / WIE SICHER / DAFÜR-DAGEGEN / EINSCHRÄNKUNG). **Keine** Scores, **keine** Fachbegriffe (kein „EG-1", „C_int", „VFP"), ≤ 250 Wörter, Analogien erlaubt.
- Ergebnis in **Plain-Vokabular**: **BESTÄTIGT / UNSICHER / FALSCH / HALTLOS / UNBELEGT**.
- Klartext zur Bezugsbasis (z. B. LCOE/LCOS, Standort, mit/ohne Speicher) ohne Score-Prozente.

## Erwarteter Hinweis (PLAIN)
Verhaltensregeln Modus B: keine Score-Prozente im Text; bei fehlender belastbarer Quelle ehrlich „kommt auf die Vergleichsbasis an", keine erfundene Zahl; HARMFUL FRAMING nur als Hinweis auf fehlende Perspektive, nie politisch.

## Bestanden, wenn
PLAIN respektiert (kein Score/Fachjargon, ≤250 Wörter) **und** Plain-Verdict-Vokabular **und** Trace vorhanden.
